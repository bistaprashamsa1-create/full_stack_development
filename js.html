JavaScript

JavaScript is the programming language of the web. It runs in the browser and allows developers to create dynamically updating content, respond to user events, validate forms, communicate with servers via APIs, and build full interactive applications.

Together with HTML and CSS, JavaScript forms the third pillar of front-end development. It can also run on the server via Node.js, making it truly full stack.

Variables & Data Types

JAVASCRIPT
// Variable declarations (ES6+)
let name = "Alice"; // reassignable
const age = 25; // constant
var legacy = "avoid"; // older — use let/const instead

// Data types
let num = 42; // Number
let flag = true; // Boolean
let arr = ["a", "b", "c"]; // Array
let obj = { key: "value" }; // Object

Functions & Arrow Functions

JAVASCRIPT
// Traditional function
function greet(person) {
  return `Hello, ${person}!`;
}

// Arrow function (ES6)
const greet = (person) => `Hello, ${person}!`;

// Higher-order functions
const nums = [1, 2, 3, 4];
const doubled = nums.map(n => n * 2); // [2,4,6,8]

DOM Manipulation

JAVASCRIPT
// Select elements
const title = document.getElementById("title");
const items = document.querySelectorAll(".item");

// Modify content and style
title.textContent = "New Title";
title.style.color = "#3a7bd5";

// Listen for events
document.getElementById("btn").addEventListener("click", () => {
  alert("Button clicked!");
});
