Bootstrap Framework

Bootstrap is the world's most popular open-source CSS framework. It provides a responsive grid system, pre-built UI components, and utility classes that make it fast to build professional, mobile-first web interfaces without writing CSS from scratch.

Bootstrap is maintained by the original Twitter team and has been downloaded billions of times. The current major version is Bootstrap 5, which dropped the jQuery dependency.

Including Bootstrap via CDN

HTML
<!-- Bootstrap 5 CSS (in <head>) -->
<link rel="stylesheet"
      href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css">

<!-- Bootstrap 5 JS Bundle (before </body>) -->
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>

The Grid System

Bootstrap's grid divides each row into 12 columns. You combine classes like col-4 (4 of 12 = one third) to create layouts. Breakpoint prefixes (sm, md, lg, xl) control how columns stack on different screen sizes.

HTML
<div class="container">
  <div class="row">
    <div class="col-md-4">Column 1</div>
    <div class="col-md-4">Column 2</div>
    <div class="col-md-4">Column 3</div>
  </div>
</div>
