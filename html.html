HTML – HyperText Markup Language

HTML is the standard markup language for creating web pages. It describes the structure of a page using a series of elements represented by tags. Browsers parse HTML and render it as the visual content the user sees.

HTML alone defines the structure and content of a page — not the visual style (that's CSS) or the behaviour (that's JavaScript). Together the three form the foundation of every website.

Common HTML Tags

<html> <head> <body> <h1>–<h6> <p> <a> <img> <ul> / <ol> <li> <table> <form> <input> <div> <span> <nav> <section> <article> <footer>

Basic Page Structure

HTML
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Web Page</title>
  </head>
  <body>
    <header>
      <h1>Hello, World!</h1>
    </header>
    <main>
      <p>Welcome to my page.</p>
      <a href="about.html">About Me</a>
    </main>
    <footer>© 2025</footer>
  </body>
</html>

HTML Forms

Forms allow users to submit data. The <form> element wraps <input>, <select>, and <button> elements. The action attribute defines where data is sent.

HTML
<form action="/submit" method="POST">
  <label for="name">Your Name:</label>
  <input type="text" id="name" name="name" required>

  <label for="email">Email:</label>
  <input type="email" id="email" name="email" required>

  <button type="submit">Send</button>
</form>

Semantic HTML

Semantic elements clearly describe their meaning to both the browser and the developer. Using tags like <header>, <nav>, <main>, <section>, <article>, and <footer> improves accessibility (screen readers) and SEO (search engines).

Non-Semantic vs Semantic

❌ Non-semantic: <div class="header"> — the tag tells us nothing about the content.
✅ Semantic: <header> — immediately clear this is a page header.

💡 Best Practice: Always use semantic HTML where possible. It makes your code more readable, improves screen-reader accessibility for users with disabilities, and helps search engines correctly index your content — all with zero extra effort.
